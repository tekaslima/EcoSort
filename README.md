# EcoSort

Aplicação web que identifica, a partir de uma fotografia ou da câmara do telemóvel, para que
ecoponto vai um resíduo: papel/cartão (azul), plástico/metal (amarelo) ou vidro (verde).

Endereço: https://tekaslima.github.io/ecosort/

- A aplicação está na raiz deste repositório (`index.html`, `app.js`, …).
- `modelo/` — modelo de reconhecimento de imagens (formato Teachable Machine).
- `projeto/` — guia de desenvolvimento, documentação do modelo, programa do Arduino e scripts de treino.
- Abrir com `#admin` no fim do endereço mostra o separador de testes.
